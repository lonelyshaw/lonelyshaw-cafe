# Lonelyroom Telegram Bot

Lonelyroom — уютная цифровая комната в Telegram.

Слоганы:

- "каждый человек — это целая комната."
- "познакомься с собой заново."

Стек:

- Python 3.11+
- aiogram 3
- SQLite

## Что умеет бот

Главное меню:

- 🏡 Моя комната
- 📖 Книга обо мне
- 🌙 Вопрос дня
- 🌧 Настроение
- 🕯 Моменты
- 💌 Письмо себе
- 🦊 Питомцы
- 🪞 Зеркало
- 🧳 Архив
- ⚙️ Настройки
- 🎬 Медиа

Интерфейс полностью на русском.
Сообщения короткие, спокойные и теплые.
Режимов персонажа нет.

Главная клавиатура постоянная: она остается под полем ввода и помогает возвращаться в комнату без команд.

Разговорный раздел не выдает случайные цитаты.
Он сохраняет последние реплики, продолжает мысль пользователя и задает короткие уточняющие вопросы.

## База данных

SQLite-файл создается автоматически при первом запуске.

По умолчанию путь такой:

```text
data/lonelyroom.sqlite3
```

Схема находится в:

```text
sql/schema.sql
```

Основные таблицы:

- `users` — пользователи Telegram;
- `book_entries` — страницы книги о себе;
- `daily_answers` — ответы на вопрос дня;
- `moments` — сохраненные моменты;
- `letters` — письма себе;
- `conversation_messages` — память разговоров;
- `moods` — настроение дня;
- `user_pets` — открытые питомцы;
- `mirror_entries` — ответы из зеркала.

## Разделы

### 🏡 Моя комната

Показывает спокойную сводку:

- 📖 страниц;
- 🕯 моментов;
- 💌 писем;
- 🌙 ответов дня;
- 🌧 настроений;
- 🦊 питомцев.

Также показывает текстовое состояние комнаты:

- 0-2 действия: `пустая тихая комната`;
- 3-5 действий: `в комнате горит маленькая лампа`;
- 6-10 действий: `на полке появляются книги и письма`;
- 10+ действий: `это место уже похоже на дом`.

Внизу остается короткий теплый текст о комнате и воспоминаниях.

### 🕯 Моменты

Пользователь сохраняет маленькое воспоминание.
Запись остается в таблице `moments`.

### 🌧 Настроение

Пользователь выбирает настроение дня:

- спокойно;
- тревожно;
- грустно;
- уютно;
- устало;
- радостно.

Настроение сохраняется по Telegram `user_id` и текущей дате в таблицу `moods`.

### 💌 Письмо себе

Пользователь пишет письмо себе будущему.
Текст сохраняется в таблице `letters`.

### 🦊 Питомцы

Первый питомец открывается после трех действий:

- ответить на вопрос дня;
- добавить страницу в книгу о себе;
- сохранить момент.

Первый питомец:

```text
🦊 Лесной лисёнок
Он появляется рядом с теми, кто учится быть мягче к себе.
```

Открытые питомцы сохраняются в таблице `user_pets`.

### 🪞 Зеркало

Бот задает вопрос:

```text
Что ты сейчас чувствуешь на самом деле?
```

Ответ сохраняется в таблице `mirror_entries`.

### 🧳 Архив

Показывает последние 5 сохраненных:

- страниц;
- моментов;
- писем;
- ответов дня.

### ⚙️ Настройки

Пока показывает приватность:

```text
Lonelyroom хранит только то, что вы сами оставляете здесь.
```

### 🎬 Медиа

Пока это уютный экран-заглушка с тремя полками:

- 📚 Книги;
- 🎬 Фильмы;
- 🎵 Музыка.

## Разговорная память

Раздел `🤍 Поговорить` ведет продолжающийся диалог.
Свободный текст вне меню тоже попадает в разговор.

Бот:

- помнит последние сообщения;
- отвечает коротко;
- продолжает мысль пользователя;
- задает follow-up вопрос;
- не использует мотивационные цитаты;
- не дает общие советы.

Примеры:

```text
Пользователь: мне грустно
Lonelyroom: расскажешь, что произошло?

Пользователь: эх
Lonelyroom: что случилось?

Пользователь: устала
Lonelyroom: давно так себя чувствуешь?
```

## Локальный запуск

### 1. Создайте бота в Telegram

Откройте `@BotFather`, создайте бота и получите токен.

### 2. Создайте виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Создайте `.env`

```bash
cp .env.example .env
```

Откройте `.env` и вставьте токен:

```env
BOT_TOKEN=ваш_токен_от_BotFather
DATABASE_PATH=data/lonelyroom.sqlite3
```

### 5. Запустите бота

```bash
python -m lonelyroom_bot.main
```

После запуска напишите боту `/start`.

## Команды

- `/start` — открыть Lonelyroom;
- `/menu` — вернуться в главное меню.
