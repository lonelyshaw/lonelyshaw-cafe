# Lonelyroom Telegram Bot

Lonelyroom — уютная цифровая комната в Telegram.

Слоганы:

- "каждый человек — это целая комната."
- "познакомься с собой заново."

Стек:

- Python 3.11+
- aiogram 3
- SQLite

## Что умеет бот

Главное меню:

- 🏡 Моя комната
- 📖 Книга обо мне
- 🌙 Вопрос дня
- 🌧 Настроение
- 🕯 Моменты
- 💌 Письмо себе
- 🦊 Питомцы
- 🪞 Зеркало
- 🧳 Архив
- ⚙️ Настройки
- 🚪 Комнаты друзей
- 💌 Записки у двери
- 🎬 Медиа

Интерфейс полностью на русском.
Сообщения короткие, спокойные и теплые.
Режимов персонажа нет.

Главная клавиатура постоянная: она остается под полем ввода и помогает возвращаться в комнату без команд.

Разговорный раздел не выдает случайные цитаты.
Он сохраняет последние реплики, продолжает мысль пользователя и задает короткие уточняющие вопросы.

## База данных

SQLite-файл создается автоматически при первом запуске.

По умолчанию путь такой:

```text
data/lonelyroom.sqlite3
```

Схема находится в:

```text
sql/schema.sql
```

Основные таблицы:

- `users` — пользователи Telegram;
- `book_entries` — страницы книги о себе;
- `daily_answers` — ответы на вопрос дня;
- `moments` — сохраненные моменты;
- `letters` — письма себе;
- `conversation_messages` — память разговоров;
- `moods` — настроение дня;
- `user_pets` — открытые питомцы;
- `mirror_entries` — ответы из зеркала;
- `room_profiles` — ник и приватность комнаты;
- `room_notes` — записки у двери;
- `room_lights` — огоньки у двери.

## Разделы

### 🏡 Моя комната

Показывает живую сцену комнаты:

- 🌧 за окном;
- 🕯 свет;
- 📚 полку;
- 🦊 питомца рядом;
- ник комнаты;
- количество страниц, моментов, писем, ответов дня, питомцев и записок у двери.

Описание комнаты меняется от активности:

- 0-2 действия: `Комната ещё почти пустая, но в ней уже есть место для тебя.`
- 3-5 действий: `В комнате стало чуть теплее. Где-то горит маленький свет.`
- 6-10 действий: `На полке появляются первые следы дней: страницы, письма и моменты.`
- 10+ действий: `Это место уже похоже на дом.`

### 🕯 Моменты

Пользователь сохраняет маленькое воспоминание.
Запись остается в таблице `moments`.

### 🌧 Настроение

Пользователь выбирает настроение дня:

- спокойно;
- тревожно;
- грустно;
- уютно;
- устало;
- радостно.

Настроение сохраняется по Telegram `user_id` и текущей дате в таблицу `moods`.

### 💌 Письмо себе

Пользователь пишет письмо себе будущему.
Текст сохраняется в таблице `letters`.

### 🦊 Питомцы

Питомцы — коллекция маленьких жителей комнаты.
Открытые питомцы сохраняются в таблице `user_pets`.

- 🦊 Лесной лисёнок — 1 ответ дня + 1 страница + 1 момент.
- 🦉 Ночная сова — 5 ответов дня.
- 🐈 Кафейный кот — 3 сохранённых момента.
- 🐇 Дождевой кролик — 3 страницы в книге.
- 🦌 Олень туманных холмов — 10 любых действий в комнате.

Экран питомцев показывает открытых и закрытых питомцев, условия открытия и описания уже открытых.

### 🪞 Зеркало

Бот задает вопрос:

```text
Что ты сейчас чувствуешь на самом деле?
```

Ответ сохраняется в таблице `mirror_entries`.

### 🧳 Архив

Показывает последние 5 сохраненных:

- страниц;
- моментов;
- писем;
- ответов дня.

### ⚙️ Настройки

Показывает приватность и ник комнаты:

```text
Lonelyroom хранит только то, что вы сами оставляете здесь.
```

Ник комнаты:

- только латинские буквы, цифры и `_`;
- от 3 до 20 символов;
- уникальный;
- без пробелов.

Приватность комнаты хранится в `room_profiles`.
Сейчас комнату можно найти по нику, если ник создан.
Личные записи гостям не показываются.

### 🚪 Комнаты друзей

Пользователь вводит ник комнаты друга, например `lonely_mila`.
Если дверь найдена, бот показывает гостевую версию комнаты:

- атмосферу;
- свет;
- питомца рядом;
- количество предметов, страниц, моментов и огоньков.

Гостям не показываются письма, полные страницы, полные ответы дня, личные разговоры и Telegram `user_id`.

### 💌 Записки у двери

Гость может оставить записку или огонёк в комнате друга.
Владелец видит новые записки при следующем входе, возврате в меню или в разделе `💌 Записки у двери`.

### 🎬 Медиа

Пока это уютный экран-заглушка с тремя полками:

- 📚 Книги;
- 🎬 Фильмы;
- 🎵 Музыка.

## Разговорная память

Раздел `🤍 Поговорить` ведет продолжающийся диалог.
Свободный текст вне меню тоже попадает в разговор.

Бот:

- помнит последние сообщения;
- отвечает коротко;
- продолжает мысль пользователя;
- задает follow-up вопрос;
- не использует мотивационные цитаты;
- не дает общие советы.

Примеры:

```text
Пользователь: мне грустно
Lonelyroom: расскажешь, что произошло?

Пользователь: эх
Lonelyroom: что случилось?

Пользователь: устала
Lonelyroom: давно так себя чувствуешь?
```

## Локальный запуск

### 1. Создайте бота в Telegram

Откройте `@BotFather`, создайте бота и получите токен.

### 2. Создайте виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Создайте `.env`

```bash
cp .env.example .env
```

Откройте `.env` и вставьте токен:

```env
BOT_TOKEN=ваш_токен_от_BotFather
DATABASE_PATH=data/lonelyroom.sqlite3
```

### 5. Запустите бота

```bash
python -m lonelyroom_bot.main
```

После запуска напишите боту `/start`.

## Команды

- `/start` — открыть Lonelyroom;
- `/menu` — вернуться в главное меню.
